02

Typography

3 roles, strict discipline
Title · Gilroy
--f-title · 700
headings, actions, labels
Discover places
Only for titles, buttons & labels-as-badges — never running text.
Body · Proxima Nova
--f-body · 400 / 600
all reading text

Build a click-to-inspect POI experience on TomTom's vector tiles — the basemap carries the POIs, no overlay duplicates. This is the voice of every description and paragraph in the app.

Code · Fira Code
--f-code · 500
code & identifiers only
reverseGeocode(lat, lon)
--c-neutral · queryRenderedFeatures

Discipline: Gilroy 700 for titles/actions/labels-as-badges · Proxima Nova for anything you read · Fira Code only for code & technical identifiers.
